# Changelog

All notable changes to MioROM will be documented in this file.

## [1.0.4] — 2026-09-14

### Added
- **Nintendo Wii Optical Disc & WBFS Partition Engine (`miorom.platforms.wii.disc` / `miorom.platforms.wii`)**:
  - Implemented pure-Python, zero-dependency reverse engineering engine for Nintendo Wii optical disc images (`.iso` / `.wii`) and sparse block containers (`.wbfs`) (`WiiDisc`, `WiiPartition`, `WiiDiscHeader`, `WiiPartitionInfo`, `WBFSDisc`).
  - Added streaming lazy cluster decryption (< 50 MB RAM usage even for full 8.5 GB dual-layer retail DVD-9 disc images) resolving 32 KB clusters on-demand.
  - Implemented physical Partition Information Table parsing at `0x40000` supporting multiple cryptographically isolated partitions (Data, Update, Channel).
  - Implemented AES-128 Title Key decryption via retail and Korean Wii Common Keys using `aes128_cbc_decrypt`.
  - Implemented 4-level hierarchical hash tree engine: 31 SHA-1 sub-hashes (H0) per 32 KB cluster, H1 group hashing (8 clusters = 160 bytes), H2 group hashing (64 clusters / 2 MB = 160 bytes), and H3 root table hashing with automatic TMD content record validation.
  - Implemented recursive depth-first FST (File System Table) builder, directory traversal, and on-demand file extraction (`sys/boot.bin`, `sys/bi2.bin`, `sys/apploader.img`, `sys/main.dol`, and nested `files/` game assets).
  - Implemented in-memory file replacement and surgical injection (`disc.partitions[0]["files/..."] = new_bytes`), automatic FST layout re-indexing, and Trucha Bug fake-signing (null RSA-2048 digital signatures) on modified Tickets and TMDs.
  - Added bi-directional repacking to standard playable `.iso` and sparse `.wbfs` containers.
- **Nintendo Wii BRRES & TEX0 Resource Engine (`miorom.platforms.wii.tpl` / `miorom.platforms.wii`)**:
  - Implemented analytical parser, builder, and texture replacement engine for Nintendo's NW4R BRRES (Binary Revolution Resource) archive container (`BRRESFile`, `TEX0Image`, `PLT0Palette`, `BresIndexGroup`, `BresIndexEntry`), the universal resource package used across modern Wii games (*Mario Kart Wii*, *Super Smash Bros. Brawl*, *Xenoblade Chronicles*, *The Legend of Zelda: Skyward Sword*, etc.).
  - Implemented pure-Python bitwise Patricia trie dictionary builder and $O(k)$ search engine (`BresIndexGroup.build()`, `find()`, `to_bytes()`, `from_bytes()`) calculating exact character indices and bit comparison discriminators matching Nintendo NW4R specifications.
  - Reused centralized Nintendo GX hardware texture codecs in `tpl.py` (`decode_gx_texture`, `encode_gx_texture`) with zero duplication, supporting CMPR (S3TC/DXT1), RGB565, RGB5A3, RGBA8, I4, I8, IA4, IA8, CI4, and CI8 with 100% zero external dependencies.
  - Implemented 100% byte-exact preservation of non-texture sections (`MDL0` 3D models, `CHR0` skeletal animations, `CLR0`, `PAT0`, `SRT0`, `SHP0`, `SCN0`) stored in `other_sections`, ensuring that editing textures never corrupts or destabilizes character models or animations.
  - Added deterministic 32-byte section alignment and relative PowerPC signed 32-bit `bres_offset` calculations.
  - Added bidirectional `to_image()`, `to_png()`, and `from_image()` support with automatic color quantization for CI4 and CI8 paletted textures.
- **Nintendo Wii WAD Package Engine & Direct U8 Bridge (`miorom.platforms.wii.u8` / `miorom.platforms.wii`)**:
  - Implemented full parser, serializer, and surgical modifier for Nintendo Wii installable packages (`WADFile`, `WADTicket`, `WADTmd`, `WADContentRecord`), used for WiiWare, Virtual Console, Channels, and DLCs.
  - Implemented standalone pure-Python table-driven AES-128-CBC cipher (`aes128_cbc_encrypt`, `aes128_cbc_decrypt`) with 100% zero external dependencies, verified against NIST SP 800-38A standard vectors.
  - Enforced strict key safety without proprietary hardcoded keys: callers supply `common_key: bytes` or `title_key: bytes` on demand, while raw chunks remain fully inspectable without keys.
  - Implemented seamless in-memory bridge between WAD contents (`.app` files) and `U8Archive` (`wad.get_u8_archive()`, `wad.set_u8_archive()`), allowing translators to directly browse, unpack, patch, and repack WiiWare game filesystems without temporary disk extraction.
  - Added automatic SHA-1 hash and size recalculation in TMD records, along with standard Trucha Bug RSA null-signature fake-signing (`wad.to_bytes(fake_sign=True)`).
  - Enhanced `U8Archive` with full mutable in-memory dictionary-like API (`__init__`, `from_bytes()`, `to_bytes()`, `save()`, `__getitem__`, `__setitem__`, `keys()`, `values()`, `items()`).
- **Sony PlayStation Portable (PSP) GIM Texture & VRAM Swizzle Engine (`miorom.platforms.psp.pbp` / `miorom.platforms.psp`)**:
  - Implemented analytical parser, builder, and zero-dependency surgical image modifier for Sony GIM (Graphic Image Map) textures and micro-tiled PSP GE VRAM swizzle layouts (`GIMImage`, `GIMFormat`, `GIMPixelOrder`, `psp_swizzle`, `psp_unswizzle`).
  - Added pure-Python mathematical codec for PSP GE 16×8-byte (128-byte) micro-tile swizzling and unswizzling across 4bpp, 8bpp, 16bpp, and 32bpp textures with zero external dependencies.
  - Added support for all standard PSP GIM pixel formats: `RGBA8888`, `RGBA5551`, `RGBA4444`, `RGBA5650`, `INDEX4` (16-color CLUT), and `INDEX8` (256-color CLUT) with deterministic chunk serialization (`to_bytes()`) and bidirectional conversion to `PNGImage` / PIL Image.
  - Implemented surgical ROM hacking sub-region patching (`patch_region()`) and sub-region extraction (`extract_region()`) enabling translators to replace dialogue font characters or UI buttons with automatic, transparent unswizzling/re-swizzling and CLUT color matching.
  - Added embedded GIM texture scanning (`find_gim_textures()`) and icon helpers (`get_icon()`, `set_icon()`) in `PBPFile`.
- **Nintendo GameCube & Wii Relocatable Module (`REL`) Engine (`miorom.link.dol` / `miorom.platforms.wii`)**:
  - Implemented analytical parser, serializer, and surgical patcher for Nintendo dynamic executable modules (`.rel`) supporting format versions 1, 2, and 3 with zero external dependencies and 100% `miorom.core.schema` serializations.
  - Implemented state-machine relocation decoder and deterministic delta bytecode rebuilder with automatic `R_RVL_NONE (201)` pagination for offset gaps > 65,535 bytes to prevent 16-bit integer truncation in large data/string sections.
  - Added engineering analytical queries: `find_relocations()`, `find_relocations_in_range()`, `find_references_to_symbol()`, and `summary()`.
  - Added surgical relocation shifting (`shift_relocations()`) allowing reverse engineers to insert expanded localized dialogue strings into data sections without breaking internal or cross-module pointer references.
  - Added non-destructive simulated PowerPC relocation resolution (`simulate_resolve_section()`, `link_against_dol()`, and `DolBinary.resolve_rel()`) to resolve 32-bit addresses (`R_PPC_ADDR32`, `ADDR16_LO`, `ADDR16_HI`, `ADDR16_HA`) and 24-bit relative branches (`R_PPC_REL24`, `REL14`) for disassembly with `UniversalDisassembler`.
- **Zero-Dependency RIFF/WAVE Audio Codec (`miorom.audio.wav_codec`) & Unified Audio CLI (`miorom audio`)**:
  - Implemented standalone `WavCodec` and `WavSound` container using purely `miorom.core.schema` with zero external dependencies. Supports encoding and decoding 8-bit unsigned, 16-bit signed, 24-bit PCM, and 32-bit IEEE float audio in mono or stereo.
  - Added seamless conversions: `VAGFile.from_wav` / `.to_wav()`, `BRRCodec.from_wav` / `.to_wav()`, `DSPADPCMCodec.to_wav()`, and centralized `ADPCMCodec.build_wav` / `read_wav` through `WavCodec`.
  - Added `miorom audio` CLI suite with `convert` (bidirectional transcoding between WAV, VAG, BRR, and DSP), `extract` (dumping WAVs from SPC audio RAM and SDAT sound archives), and `info` (inspecting sample rate, bit depth, channel layout, sample count, duration, and container headers with optional `--json` output).
- **Zero-Dependency PNG Codec & Standalone Image I/O (`miorom.graphics.png_codec`)**: Extracted and expanded the pure-Python PNG codec into a first-class module (`PNGCodec`, `PNGImage`, `PNGColorType`). Supports all PNG reconstruction filter algorithms (None, Sub, Up, Average, Paeth), multiple color modes (Grayscale, RGB, RGBA, Indexed with PLTE, Grayscale+Alpha with tRNS), and sub-byte bit depths (1, 2, 4, 8).
- **Zero-Dependency Graphics Fallbacks across All Platform Formats**: Unblocked image export/import without Pillow across `ImageBridge`, `TIMImage` (PSX), `TPLFile` (Wii/GC), `BTIImage` (Wii/GC), `NCERFile` (NDS), `NSBTXFile` (NDS), `GlyphBank`, and `MemoryCard` (PSX). Added dedicated `.to_png()` / `save_icon_png()` methods to enable seamless extraction and insertion of textures, tiles, fonts, and icons directly into PNG files even in strictly zero-dependency environments.
- **Unified CLI Patching Suite & Patch Inspection (`miorom patch`)**: Added hierarchical `miorom patch` subcommands (`apply`, `create`, `inspect`) supporting BPS, IPS, PPF (v1/v2/v3), UPS, and XDelta with automated format detection via header magic bytes and extension fallback. Added standalone `inspect_patch()` and `.inspect()` methods across patchers to diagnose target sizes, CRC32 checksum validity, and record counts without altering ROMs.

### Changed
- **Unified Binary Serialization via `miorom.core.schema`**: Fully deprecated and eliminated raw Python `struct` imports across all 114 engine modules in `src/miorom`. All binary deserialization, packing, bytefield definitions, and endian-aware operations are now routed natively through `miorom.core.schema` (`BinaryStruct`, `U8`, `I8`, `U16`, `I16`, `U32`, `I32`, `U64`, `I64`, `Float32`, `Float64`, `schema.pack`, `schema.unpack`, `schema.unpack_from`, `schema.pack_into`, `schema.calcsize`, `schema.Struct`, `schema.error`), achieving zero direct dependencies on raw `struct` outside of the core schema engine.

### Fixed
- **`interleave_smd` — non-16KB chunk zero-padding (`miorom.platforms.md.rom`) (BUG-89)**: Non-16KB-aligned Sega Genesis ROMs are now zero-padded to the next 16KB boundary before interleaving into Super Magic Drive format to prevent payload corruption.
- **`RomIntegrityManager.fix` — preservation of SMD container format (`miorom.core.integrity`) (BUG-91)**: Auto-fixing Mega Drive ROM checksums now correctly checks if the input was SMD format and re-interleaves back into SMD before returning.
- **`MSBTFile.from_bytes` — invalid string offset alignment preservation (`miorom.text.msbt`) (BUG-92)**: Invalid out-of-bounds string offsets now fallback to empty strings instead of desynchronizing the label-to-message mapping.
- **`MSBTFile` — control tag null bytes string truncation (`miorom.text.msbt`) (BUG-93)**: Control tags (`0x000E`) containing null bytes in their argument payloads now properly advance the parser position without truncating the message text.
- **`GBASavePatcher.patch_to_sram` — 7-byte FLASH_V string replacement (`miorom.save.gba_save`) (BUG-94)**: Replaced 7-byte `b"FLASH_V"` with 7-byte `b"SRAM_V\x00"` instead of 6-byte `b"SRAM_V"`, avoiding trailing phantom characters in patched ROM headers.
- **`PlanarTileCodec` — SNES Mode 7 linear chunky encoding (`miorom.graphics.planar`) (BUG-95)**: Mapped Mode 7 tiles to linear chunky 8bpp format rather than bitplane planar formats.
- **`MDECVideoDecoder` — 0xFE00 EOB token draining & chroma quantization (`miorom.graphics.mdec`) (BUG-96, BUG-97)**: Correctly drains trailing `0xFE00` EOB marker on coefficient overflow and added support for custom chroma quantization tables.
- **`PPFPatcher.apply_stream` — truncated target image rejection (`miorom.patch.ppf`) (BUG-98)**: Rejects target images smaller than the required validation block offset when non-dummy validation blocks are present.
- **`BMFont.to_bitmap_font` — unicode code point bounds check (`miorom.text.bmfont`) (BUG-99)**: Wrapped character conversion with validation to prevent unhandled `ValueError` when glyph IDs exceed `0x10FFFF`.
- **`BMGFile.from_bytes` — string pool offset bounds checking (`miorom.text.bmg`) (BUG-100)**: Out-of-bounds DAT1 message offsets are safely caught and assigned empty strings.
- **`BRRCodec.encode_block` — shift selector middle range threshold (`miorom.audio.brr`) (BUG-101)**: Lowered shift threshold from `max_res > 7` to `max_res > 3` to eliminate clipping in small-amplitude audio samples.
- **`SDATContainer.to_bytes` — empty SYMB block INFO offset & FAT header count (`miorom.audio.sdat`) (BUG-102, BUG-103)**: Fixed INFO block offset to start at 64 when SYMB is absent, and ensured the FAT block header count reflects the total entry count.
- **`SappyCodec.parse_sample` — fixed-point 10-bit pitch conversion (`miorom.audio.sappy`) (BUG-104)**: Corrected sample rate calculation to divide fixed-point pitch by 1024 (`pitch >> 10`).
- **`VAGCodec.encode` — SPU-ADPCM shift filter direction (`miorom.audio.vag`) (BUG-105)**: Inverted shift search order to select optimal scaling factors starting from smallest scale (12) down to 0.
- **`XAStreamDecoder.decode_sector` — continuous filter state across sound units (`miorom.audio.xa`) (BUG-106)**: Sequential sound units now preserve filter prediction history across sound units within CD-XA sectors.
- **`Elf32RelaStruct` — signed relocation addend packing (`miorom.link.elf`) (BUG-107)**: Packed `r_addend` as signed 32-bit integer (`I32`) to properly support negative relocation addends.
- **`PatternScanner.iter_file` — overlapping chunk duplicate prevention (`miorom.scanner.pattern`) (BUG-108)**: Tracks maximum yielded offset to prevent duplicate matches across sliding buffer windows.
- **`DeepScanner.scan` — trailing partial block entropy averaging & NARC BOM endianness (`miorom.scanner.deep`) (BUG-109, BUG-110)**: Counts exact processed blocks in Shannon entropy calculation and properly resolves BOM endianness (`0xFEFF` vs `0xFFFE`).
- **`DolBinary.__init__` — immutable bytes input conversion (`miorom.link.dol`) (BUG-111)**: Wraps binary input in `bytearray()` to prevent `TypeError` when modifying sections in-place.
- **`CascadingArchive.unpack` — bounded entry count validation (`miorom.archive.cascading`) (BUG-112)**: Validates declared entry count against payload length before allocating memory buffers.
- **`LZ10.compress` & `LZ11.compress` — sliding window `rfind` upper bound allows forward self-reference (`miorom.compression.lz10`, `miorom.compression.lz11`)**: The lookahead match search previously used `search_pos + 3` as the `rfind` upper boundary, allowing matches starting ahead of `search_pos` to produce zero or negative displacement backreferences, causing decompressors to fail with `CompressionError: invalid displacement`. Fixed boundary to `search_pos + 1` and constrained lookahead extension to `pos + match_len < in_pos`.
- **`APLib._BitWriter.put_gamma` — zero bit emission on unit value (`miorom.compression.aplib`)**: Variable-length gamma coding for `val <= 1` executed 0 loop iterations in `while temp > 1`, emitting 0 bits and corrupting all downstream bitstreams. Added explicit base-case check emitting a single `0` terminator bit for `val <= 1`. Also expanded maximum sliding window lookback from 32,000 to standard 32,767 (`0x7FFF`) bytes.
- **`RLE.compress` — off-by-one run length cap & unhandled end marker (`miorom.compression.rle`)**: Encodable run length cap was clamped to `run_len < 130` (max 129), underutilizing the 7-bit length field which supports runs up to 130 (`0x7F + 3`). Fixed condition to `run_len < (0x7F + 4)`. Additionally implemented missing `include_end_marker` behavior to emit `END_OF_STREAM` (`0xFF`) when requested.
- **`calc_mips_jump` & `_disasm_mips` — 256MB segment validation and delay-slot base address (`miorom.asm.branch`, `miorom.asm.disasm`)**: Added optional `src_addr` parameter to `calc_mips_jump()` with upper 4-bit segment checking against the delay slot PC (`src_addr + 4`), preventing invalid cross-segment jumps. Fixed MIPS J/JAL target address reconstruction in `UniversalDisassembler` to calculate upper bits from `(address + 4) & 0xF0000000`.
- **`BranchRelocator.rebase_block` & `TrampolineHook` — out-of-range ARM branch protection & 6502 16-bit address guard (`miorom.asm.reloc_calc`, `miorom.asm.trampoline`)**: ARM branch rebasing in `rebase_block()` now checks `item.in_range` before writing rebased instruction bytes to avoid corrupting out-of-range branches. Added explicit bounds checking to `TrampolineHook.create_6502_hook()` to ensure `cave_ram_addr <= 0xFFFF` before packing 16-bit JMP targets. Documented architectural limitations regarding PC-relative displaced instructions in ARM, Thumb, and PowerPC trampolines.
- **`NDSRom.replace_file` & `get_banner_title` — FAT table shift tracking & UTF-16-LE alignment (`miorom.platforms.nds.rom`)**: Replacing ROM files with larger data buffers shifted the underlying bytearray but left `self.fat_offset` and downstream FAT record pointers pointing to pre-shift locations, corrupting FAT tables. Updated `replace_file()` to adjust `self.fat_offset` when the FAT resides after the replaced region. Fixed banner title string truncation to align down to even boundaries (`null_pos - (null_pos % 2)`) to avoid corrupting UTF-16-LE character pairs.
- **`NARCFile._parse_btnf_names` & `PSXSaveHeaderStruct` — flat-file BTNF name parsing & save title field bounds (`miorom.platforms.nds.narc`, `miorom.platforms.psx.memory_card`)**: Implemented flat-file BTNF name table parsing in `NARCFile` so extracted files retain real filenames instead of generic numbers. Partitioned `PSXSaveHeaderStruct` title field into 32-byte Shift-JIS title and 32-byte reserved padding, preventing garbage characters in parsed save titles.
- **`VFSFile.truncate` & IPS32 Truncation Guard (`miorom.archive.vfs`, `miorom.patch.ips`)**: Implemented missing `VFSFile.truncate(size=0)` method to prevent `AttributeError` crashes when opening existing virtual files in write mode. In `IpsPatcher.apply()`, guarded trailing IPS32 truncation sizes with `0 < trunc_size < len(result)` to prevent trailing archive padding from wiping patched buffers.
- **`SSEQSequence` & `SSEQTrack` — MIDI transpiler delta-times, loop preservation & tempo endianness (`miorom.audio.sseq`)**: Fixed opcode 0xE0 tempo decoding from big-endian to little-endian (`<H`). Implemented two-pass loop compilation in `_compile_track_events()` so `loop_start` and `loop_end` markers emit compliant `0x94` jumps instead of being silently dropped. Added individual 0-tick VLQ delta times between consecutive RPN CC messages (CC101, CC100, CC6, CC38) for pitch bend range in MIDI output. Replaced fragile dummy-event RPN detection in `from_midi()` with persistent track-level state variables.
- **`ScriptVM` & `BytecodeStreamSplicer` — signed integer argument emission & relative branch counts (`miorom.script.vm`, `miorom.script.splicer`)**: Assembler Pass 2 now handles `s8`, `s16`, and `s32` argument types without silently dropping operands. In `BytecodeStreamSplicer.splice_and_shift()`, restricted operand repacking and `adjusted_count` increments to branches that actually cross the splice boundary.
- **`PointerRelinker` & `StringTablePipeline` — banked pointer table scanning & signed relative pointer extraction (`miorom.text.pointer_relinker`, `miorom.text.pipeline`)**: Added `bank_table: Optional[List[int]]` parameter to `PointerRelinker.scan_pointer_table()` to properly map per-entry bank numbers in banked pointer tables. Added two's-complement sign extension to `raw_ptr` in `StringTablePipeline.extract_strings()` when `is_relative=True`, restoring extraction of backward-relative script pointers.
- **`KosinskiCodec.compress` — descriptor high-byte truncation (`miorom.compression.kosinski`)**: Flushing the final descriptor word omitted writing `out[desc_pos + 1] = (val >> 8) & 0xFF`. For inputs where remaining descriptor bits exceeded 8 bits, bits 8..15 were zeroed, causing the decompressor to misinterpret literal bytes as invalid backreferences and fail with `CompressionError`. Fixed by writing both descriptor bytes during finalization.
- **`BpsPatcher.parse` — null-byte dropping and linear overhead in expanded ROMs (`miorom.patch.bps`)**: Converting BPS patches into concrete `PatchHunk` records filtered expanded ROM bytes using `if byte:`, silently omitting all `0x00` bytes in target expansion areas. Replaced byte-by-byte iteration with unified slice hunk emission (`PatchHunk(source_len, output[source_len:])`), preserving all data bytes and accelerating parsing from $O(N)$ to $O(1)$.
- **`BranchRelocator` — missing second-halfword validation for Thumb BL (`miorom.asm.reloc_calc`)**: Re-basing Thumb branch instructions unpacked the second halfword into `raw_val2` but never verified the prefix/suffix match `(raw_val2 & 0xF800) == 0xF800`. Added validation so non-BL 32-bit Thumb instructions starting with `0xF000` are not corrupted and correctly raise `ValueError`.
- **`PowerPCBranch.encode_b` — out-of-range absolute branch silent truncation (`miorom.asm.branch`)**: Boundary checks for PowerPC branch encoding explicitly bypassed absolute branches (`if not absolute`). Because PowerPC `BA`/`BLA` instructions only provide a 26-bit effective address range, passing physical memory addresses (e.g. GameCube/Wii RAM `0x80000000`) caused silent truncation via `& 0x00FFFFFF` to `0x00000000`. Added explicit validation ensuring absolute targets fit within the 26-bit signed addressing window.
- **`resolve_mips_jump` — pipeline delay slot address mismatch (`miorom.asm.branch`)**: Standalone MIPS jump target resolution calculated upper segment bits using `src_addr & 0xF0000000` instead of `(src_addr + 4) & 0xF0000000` (the delay slot PC). Updated to align with `MIPSBranch.decode_j()` and the official MIPS architecture specification.
- **`apply_outline_1px` — missing image buffer size validation (`miorom.graphics.pixel_math`)**: Added upfront validation ensuring `len(rgba_bytes) == width * height * 4`, preventing unhandled `IndexError` exceptions on truncated or malformed image buffers.
- **Codebase Hardening & Linter Compliance (`miorom.*`)**: Standardized and hardened variable names and binary spec unpacks across the entire codebase for strict Ruff and Flake8 compliance. Resolved ambiguous variable names (`l` -> `match_len`, `length`, `run_len`), documented intentionally unconsumed binary format spec fields with leading underscore prefixes (`_bom`, `_version`, `_file_size`, `_curr_tile`, `_min_hook_size`), deduplicated namespace exports in `__init__.py`, and resolved circular import dependencies between `core.integrity` and `text.pipeline` without altering any binary parsing behaviors.
- **Namespace Cleanliness & Export Deduplication (`miorom.__init__`, `miorom.errors`)**: Resolved duplicate and out-of-order exports in `__init__.py` (`XRefAnalyzer`, `XRefGraph`, `XRefType`, `AssetProtocol`, `ArchiveProtocol`, `EmulatorClientProtocol`), moved late module imports prior to `__all__`, and removed duplicate `Optional` typing import in `errors.py`.
- **`cmd_disasm` — `UniversalDisassembler` calls undefined `disassemble_stream` (`miorom.cli.main`)**: Executing the `miorom disasm` CLI command on non-m68k architectures crashed with an `AttributeError` because it called `disassemble_stream`. Updated to call the correct `disassemble` descriptor method with `base_address` and `max_instructions` arguments.
- **`cmd_scan_text` — `TranslationRow` instantiated with unexpected `length` argument (`miorom.cli.main`)**: Exporting scanned dialogue strings to a CSV file (`miorom scan-text --output`) threw a `TypeError` due to an unexpected `length` keyword argument being passed to `TranslationRow`. Removed the invalid argument.
- **`ROM Handler` — `GBRom` property typo `cartridge_type_name` (`miorom.rom.handlers.cartridge`)**: Processing Game Boy ROMs through the universal ROM handler triggered an `AttributeError` because it attempted to access `.cartridge_type_name` instead of the actual `.cartridge_type` property. Fixed the property reference.
- **Missing Module Exports (`miorom.__init__`)**: The `__all__` export list declared several symbols (`NESRom`, `NESHeaderStruct`, `PBPFile`, `SFOFile`, `NARCEntry`, `XRefDirection`) that were never imported into the namespace, causing `undefined-all-variable` linting errors. Added the missing imports from their respective platform modules.
- **Missing `NCLRFile` Typing Import (`miorom.platforms.nds.ncer`)**: Added missing `NCLRFile` import to fix `F821 undefined name` linting errors during type hint evaluation.
- **`LZExtendedSizeStruct` & `RLEExtendedSizeStruct` — missing definitions and imports for extended sizes (`miorom.compression.lz11`, `miorom.compression.rle`)**: Decompressing large LZ11 or RLE streams (> 0xFFFFFF bytes or 0-size fallback) triggered fatal `NameError` exceptions due to missing struct definitions and imports. Added missing imports and defined `RLEExtendedSizeStruct` locally in `rle.py` to restore extended size support.
- **`ExtractArchiveStep` & `PackArchiveStep` — mismatched U8Archive classmethod signatures (`miorom.pipeline.engine`)**: The pipeline engine incorrectly called non-existent `U8Archive.from_bytes()` and `from_directory()` methods, crashing during U8 archive tasks. Fixed by using the correct `U8Archive.extract_all()` and `U8Archive.pack()` API methods.
- **`LiteralRelocator` — `scan_all` method missing from `UniversalInstructionScanner` (`miorom.asm.literal_relocator`)**: The universal fallback path for literal relocation called an undefined `scan_all` method. Replaced with the correct `find_code_pointers` method and updated the data argument to `code`.
- **`table_detector` — unreachable code and undefined variables (`miorom.scanner.table_detector`)**: The `extract_strings` method contained a leftover, unreachable `return extracted` statement after a valid list return. Cleaned up the dead code.
- **Missing Domain Exceptions and Typing Imports (`miorom.*`)**: Standard domain exceptions (`ParseError`, `RelocationError`) and typing hints (`List`, `Tuple`, `Any`, `Sequence`) were omitted from imports in several modules (e.g. `expander.py`, `tilesheet.py`, `vm.py`, `vwf.py`, `heap.py`, `ncgr.py`, `sfo.py`, `u8.py`), masking underlying parsing errors as fatal `NameError` exceptions. Injected all missing top-level module imports to restore correct error propagation and type resolution.
- **`AutoRelocationManager` — relative pointer arithmetic inverted (`miorom.patch.relocator`)**: `read_pointer_value` and `write_pointer_value` previously calculated relative targets using `base_address + raw_val` and `new_target_offset - base_address`. Fixed to compute relative targets from the pointer's own buffer location (`pointer_offset + raw_val` and `new_target_offset - pointer_offset`) with signed delta support.
- **`PointerRelinker.relink` — free-space search colliding with pointer tables (`miorom.text.pointer_relinker`)**: In ROMs filled with the designated fill byte (e.g. `0xFF`), `find_free_space()` could allocate memory inside the pointer table range, corrupting subsequent pointers during batch relinking. Added `protected_ranges` support to guarantee free-space runs never overlap pointer tables or active allocations.
- **`DialogueDissector.extract_from_table` — target offset calculation ignores `pointer_type` (`miorom.script.dialogue_dissector`)**: Hardcoded subtraction of `base_address` broke relative and banked pointer tables. Added `pointer_type` and `bank` parameters to `extract_from_table` and delegated offset resolution to `PointerRelinker._to_rom_offset()`.
- **`DialogueDissector.inject_translations` — relocation pointer rewrite uses absolute arithmetic (`miorom.script.dialogue_dissector`)**: Relocated string pointers were rewritten using `allocated_off + block.base_address` regardless of addressing mode. Now delegates to `relinker._to_pointer_value(allocated_off, pointer_type, bank)` to properly format relative and banked pointer updates.
- **`SmartScriptRepacker.repack_with_translations` — label drift on unknown multi-byte opcodes (`miorom.script.repacker`)**: Unregistered instructions with raw multi-byte payloads were sized as single-byte instructions during Pass 1, skewing subsequent branch label offsets. Sizing and emission now account for `raw_bytes` payloads.
- **`SmartAutoPaginator.paginate_text` — manual newlines collapsed inside paragraphs (`miorom.text.paginator`)**: Splitting text with whitespace-collapsing `.split()` stripped explicit `\n` linebreaks chosen by translators. Updated to process paragraph lines independently and preserve hard line breaks.
- **`find_pane` — NUL-padded pane name matching failure (`miorom.platforms.wii.brlyt`)**: Comparing 16-byte fixed-string pane names directly failed when entries contained trailing NUL padding. Now strips trailing `\x00` characters from both search target and candidate names.
- **`apply_vertical_gradient` — missing buffer validation (`miorom.graphics.pixel_math`)**: Added buffer length validation ensuring `mask_bytes` matches expected 8-bit mask or 32-bit RGBA dimensions, and documented source alpha channel modulation behavior.
- **`VWFHookEngine.synthesize_width_routine` — Thumb routine jumps into 32-bit literal pool (`miorom.asm.vwf_hook_engine`)**: In 16-bit Thumb mode, `B .done` branched directly to offset `0x10` where `table_vaddr` was stored as raw 32-bit data, causing the processor to execute address bytes as instructions. Updated routine layout to branch cleanly over the 4-byte literal pool (`B .after_pool`) to offset `0x18`, loading via PC-relative `LDR r2, [PC, #12]` with proper 4-byte boundary alignment.
- **`DynamicVWFInjector.generate_arm_vwf_hook` & `generate_mips_vwf_hook` — premature return inside trampoline caves (`miorom.text.vwf_injector`)**: Embedding generated ARM and MIPS lookup routines into `TrampolineHook`'s inline cave payload caused premature subroutine returns (`BX lr` / `jr $ra; nop`) before displaced instructions and trampoline return branches could execute. - **`ThumbBranch.encode_b` — missing 11-bit branch range check (`miorom.asm.branch`)**: Unconditional 16-bit Thumb `B` instructions have an 11-bit signed halfword displacement (`[-2048, 2046]` bytes). Target offsets exceeding this limit were silently masked via `& 0x7FF`, generating branches to corrupted addresses. Added range check raising `RelocationError` on overflow, along with `decode_b()` and `decode_bl()` decoding helpers.
- **`Yaz0.compress` — lookback window unbounded by `MAX_DIST` (`miorom.compression.yaz0`)**: When `search_depth` exceeded `MAX_DIST` (4096 bytes), `start_window` lookback calculation allowed match distances greater than 4096, which overflowed the 12-bit distance field and corrupted compressed output. Capped `start_window` to `src_pos - min(src_pos, min(search_depth, MAX_DIST))`.
- **`DteCodec.encode` — unmapped Unicode characters silently truncated (`miorom.text.dte`)**: Non-ASCII Unicode characters unmapped by the provided charmap or without a charmap were truncated to 8 bits via `ord(ch) & 0xFF`, silently altering characters into unrelated ASCII codes. Now raises `ValueError` when `ord(ch) > 0xFF`.
- **`JapaneseCharMapMiner.search_kana_word` — 2-byte search skips unaligned ROM offsets (`miorom.text.japanese_charmap`)**: In 2-byte search mode, candidate positions stepped by 2 bytes, missing 16-bit Japanese character sequences located at odd byte offsets (e.g. following 1-byte command opcodes). Updated search to advance by 1 byte.
- **`TagSyntaxValidator.validate` & `TagManager.decode_tags` — bracket ordering ignored and escaped newlines conflated (`miorom.text.tags`)**: `TagSyntaxValidator.validate` relied on simple bracket counts, incorrectly validating reversed (`]...[`) and nested (`[[...]]`) brackets; replaced with a bracket stack validator. `TagManager.decode_tags` previously replaced literal `\\n` with `<ENTER>`, destroying escaped strings; made escaped newline conversion optional via `convert_escaped_newlines: bool = False`.
- **`AFSArchive` — hardcoded ASCII encoding corrupts Japanese TOC filenames (`miorom.archive.afs`)**: TOC filenames in CRI AFS archives were strictly decoded and encoded using ASCII, replacing Shift-JIS / CP932 characters common in Dreamcast, Saturn, and PS2 titles with replacement characters. ### Fixed
- **`ScriptVMDissector.splice_and_relink` — branch operand offset off by `base_offset` (`miorom.script.script_dissector`)**: All branch operand write positions were computed as absolute ROM offsets, but `new_buf` is a 0-indexed local script slice. - **`ScriptVMDissector.splice_and_relink` — length-prefix overflow raises generic error (`miorom.script.script_dissector`)**: For `has_length_prefix=True` instructions, translations longer than 255 encoded bytes raised a bare `ValueError` from `bytearray.append()` with no indication of which instruction caused it. A relative pointer is an offset from the pointer's own ROM location; the correct formula is `ptr_location + raw_ptr`. The previous behavior produced garbage file offsets whenever `base_address != 0`, causing silent extraction of wrong bytes and corrupted `.po` output.
- **`StringTablePipeline.inject_from_po` — `RomIntegrityManager.fix()` size mismatch silently left checksum partially uncovered (`miorom.text.pipeline`)**: When the integrity manager returned a buffer shorter than the post-relocation ROM, the unconditional `buffer[:len(fixed_data)] = fixed_data` slice left the relocation tail with stale checksum coverage. Emits a `RuntimeWarning` when sizes differ; uses `buffer[:] = fixed_data` for the matching-size path.
- **`NestedArchiveVFS` class methods `read` / `write` / `list` — writes silently discarded (`miorom.core.vfs`)**: All three class methods instantiated an empty `NestedArchiveVFS()` with no root path. `write()` mutations were never saved to disk. Methods now infer the root archive path from the first URI segment and load/save through it. `write()` accepts an optional `output_path` parameter.
- **`NestedArchiveVFS` — unsupported container format error does not name supported formats (`miorom.core.vfs`)**: `ParseError` on unrecognized headers (e.g. RARC, AFS) now explicitly states which formats are supported (U8, Yaz0-compressed U8) instead of reporting a generic parse failure.
- **`extract_or_quantize_palette` — all-transparent image collapses to single palette entry (`miorom.platforms.wii.tpl`)**: Images where all unique pixel colors have alpha < 128 (e.g. particle effects) produced a palette of only `(0,0,0,0)`, losing all pixel data silently.
